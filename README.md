# Literate Parakeet - 中高考成绩批量自动化查询系统

![Version](https://img.shields.io/badge/version-3.0-blue.svg)
![Python](https://img.shields.io/badge/python-3.12%2B-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

**Literate Parakeet** 是一款专为上海市教育考试院查分系统设计的自动化工具。本工具从最初的单纯截图，演化为了配备现代化 Web GUI 仪表盘、全自动多线程验证码识别（基于深度学习）以及智能成绩提取的综合解决方案。

## 🌟 核心特性 (Features)

*   **现代化 Web GUI 控制台**：完全抛弃繁琐的代码配置。一键调整行列映射、CSS 选择器匹配规则。支持浅色/深色 (Dark Mode) 外观秒切。
*   **Playwright 引擎驱动**：内置高容错异步爬虫，支持显示或隐藏后台浏览器执行。
*   **智能验证码识别**：集成 `ddddocr` 深度学习库，支持验证码错误后自动重试，解放双手。
*   **精准智能匹配提取**：支持“自动智能匹配”、“行号切片范围”、“自定义 CSS 选择器”三种维度，无论网站写法多“草台”，总有一种能抓到分数。
*   **断点续传与多线程保护**：支持覆盖或跳过已有成绩，后台多线程与 Flask 完美隔离，避免死锁与卡顿。

## 🚀 安装与环境配置 (Installation)

### 1. 环境依赖
确保您的计算机上已安装 **Python 3.12** 或更高版本。

### 2. 克隆与安装
```bash
git clone https://github.com/RJcxy/literate-parakeet.git
cd literate-parakeet

# 建议使用虚拟环境 (可选)
python -m venv venv
venv\Scripts\activate  # Windows

# 安装 Python 依赖
pip install -r requirements.txt

# 安装 Playwright 对应的浏览器内核
playwright install chromium
```

## 💡 使用指南 (Usage)

1. **准备数据模板**：
   在根目录下的 `excel/` 文件夹中准备好您的考生信息表格（如 `报名号.xlsx`）。
   确保包含所需的必要字段（如：姓名、准考证号、密码）。

2. **启动服务**：
   务必在项目**根目录**下执行：
   ```bash
   python src/app.py
   ```
   *注意：系统启动后，将自动在浏览器中打开控制台页面 `http://127.0.0.1:5000`。*

3. **配置参数**：
   - 网页端可随时通过右侧“浏览”或拖拽来载入 Excel 表格。
   - 输入目标考试院的网址。
   - 配置“行列映射”（告诉系统哪一列是姓名、哪一列是准考证号）。
   - 若网页标签更改（如大写 `BMH` 改为小写 `bmh`），可打开左下角“高级自适应配置”手动修改对应的 CSS Selector 提取规则。

4. **一键开跑**：点击“开始运行”！您可以全程在右侧的监控终端以及进度表中察看所有考生的查询进度和抓取到的最终分数。
